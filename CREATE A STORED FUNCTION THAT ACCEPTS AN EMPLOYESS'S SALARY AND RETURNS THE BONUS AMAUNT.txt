13. CREATE A STORED FUNCTION THAT ACCEPTS AN EMPLOYESS'S SALARY AND RETURNS THE BONUS AMAUNT.



Step 1: Create Function

CREATE OR REPLACE FUNCTION GET_BONUS
(P_SAL NUMBER)
RETURN NUMBER
IS
BEGIN
    RETURN P_SAL * 0.10;
END;
/


Step 2: Execute Function


SELECT GET_BONUS(30000) FROM DUAL;
